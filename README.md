# Customer Churn Prediction

An end-to-end machine learning project for predicting customer churn from customer demographic, service, contract, and billing information.

## Project Overview

Customer churn prediction is a binary classification problem:

- `0` → Customer stays
- `1` → Customer churns

The project covers the complete data science workflow:

1. Data inspection
2. Data cleaning
3. Exploratory data analysis
4. Logistic Regression baseline
5. Random Forest comparison
6. Cross-validation
7. Classification threshold optimization
8. Final model evaluation
9. Model serialization
10. Streamlit deployment

## Dataset

The project uses the Telco Customer Churn dataset.

The cleaned dataset contains:

- 7,032 customers
- 19 input features
- 1 target variable
